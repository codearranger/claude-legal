# Florida Quality Check

Final review before filing a Florida civil document.

## Format pass

- [ ] **Caption**: correct court (Circuit vs. County vs. Small Claims);
  correct judicial circuit number; `IN AND FOR [COUNTY] COUNTY, FLORIDA`;
  ends with `_____/`
- [ ] Case number in the caption matches the court's numbering format
- [ ] Division letter or case type code present if required
- [ ] All parties identified correctly (given names, not just surnames)
- [ ] Proper party designations (Plaintiff / Defendant; Petitioner /
  Respondent for family matters)
- [ ] Document dated; signed; attorney's Florida Bar number (if attorney);
  address and phone number
- [ ] Font ≥ 12 pt; 1-inch margins; 8.5×11
- [ ] PACE-ready PDF (bookmarked if over 25 pages per court practice)

## Content pass

- [ ] Every legal claim is tied to a specific Florida Statute or Rule
- [ ] Fact allegations are specific and not conclusory (Florida fact-
  pleading standard)
- [ ] Affirmative defenses specifically pled
- [ ] Compulsory counterclaims included or noted as not applicable
- [ ] Relief requested is specific

## Deadline pass

- [ ] SOL has not run (§ 95.11 — verify applicable limitation period)
- [ ] Answer/response filed within 20 days of service date
- [ ] Motion notice period: 20 days satisfied

## Service-of-process readiness

- [ ] Summons prepared (Florida form or court-approved form)
- [ ] Process server arranged (sheriff or certified process server)
- [ ] All defendants named and addresses identified for service
