# Florida File Packet

## Initial filing checklist — Circuit Court civil case

### Documents to file

1. **Civil Complaint** (properly captioned, fact-pled)
2. **Civil Cover Sheet** (AOSC 20-23 or court-approved form)
3. **Summons** (one per defendant; Florida form or court-
   approved summons)
4. **Filing fee** — verify current fee at the clerk's website;
   pay through PACE or at the clerk's window

### PACE eFiling steps

1. Log in to PACE: `https://myflcourtaccess.flcourts.org`
2. Select the correct court and case type
3. Attach all documents as PDF
4. Pay filing fee electronically
5. Retain the PACE confirmation number and the
   **file-stamped conformed copies** from PACE

### After filing

1. **Arrange process service**: contact the sheriff's office
   (civil process division) or a certified process server
   (Fla. Stat. § 48.021)
2. Provide the process server with the file-stamped summons
   and complaint
3. File **Return of Service / Proof of Service** when
   received from the process server
4. Service must be completed within **120 days** of filing
   (Rule 1.070(j)); file a motion for extension if needed

## Defendant filing checklist — responding to a complaint

1. **Answer** (within 20 days of service)
   - Include all affirmative defenses (waived if not raised)
   - Include compulsory counterclaims if any
2. File and serve through PACE
3. If MTD filed instead of answer: MTD tolls the answer
   deadline; answer due 10 days after MTD denied
