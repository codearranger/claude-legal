# Pennsylvania Civil Hearings

## Scheduling motions for hearing

Pennsylvania motion practice varies significantly by county.

### Philadelphia CCP
- **Motion Court** (Civil Administrative Judge): certain
  motions are decided in motion court without a hearing
- Full briefing + oral argument scheduled through the
  judge's chambers
- Local Rule 208.3 governs briefing deadlines

### Allegheny County
- Motions filed with the CCP; judge's chambers sets a
  briefing schedule
- Oral argument scheduled on the court's argument list

### General practice (statewide)
1. File the motion and serve all parties
2. Opposing party files an answer/response within the
   briefing period set by local rule (typically 14-30 days)
3. Moving party may file a reply within a shorter period
4. Court schedules oral argument or decides on the papers

## Argument list

Many CCP courts have a weekly or monthly **Argument List**
for motions ready for decision. Contact the court's
administrative office to list the motion for argument.
