# Pennsylvania Draft Proposed Order

```
IN THE COURT OF COMMON PLEAS OF [COUNTY] COUNTY, PENNSYLVANIA

[CIVIL DIVISION]

[Caption]

                              ORDER

         AND NOW, this ___ day of __________, 20___, upon
consideration of [Party]'s [Motion], and any response thereto,
it is hereby ORDERED and DECREED that:

         1.  [First decretal paragraph — specific relief]

         2.  [Additional decretal paragraphs]

         3.  [Scheduling, further proceedings if any]


                          BY THE COURT:


                          ___________________________________
                                                         J.

Copies to:
[All parties / counsel]
```

## Submission protocol

Submit proposed orders to the court through:
- PACFile (attach as a separate proposed-order document)
- Email to the judge's chambers (if the judge's chambers
  practice directs — check the judge's standing orders)
- Mail to the prothonotary (for some counties)
