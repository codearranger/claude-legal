# Pennsylvania File Packet

## Initial filing — CCP civil case

### Option 1: File a Complaint directly

1. **Complaint** (captioned, verified)
2. **Civil Cover Sheet** (county-specific; check court website)
3. **Filing fee** — verify current fee schedule at
   `https://ujsportal.pacourts.us` or the county prothonotary
4. **Service**: after filing, arrange service on defendant
   - Pennsylvania allows service by **certified mail** (return
     receipt requested) as the default for in-state defendants
   - Sheriff service available; process server authorized by
     Pa. R.C.P. 400.1

### Option 2: File a Praecipe for Writ of Summons (to preserve SOL)

If the SOL is about to expire but the complaint is not ready:
1. File a **Praecipe for Writ of Summons** (Pa. R.C.P. 1007(1))
   — this opens the action and tolls the SOL
2. The prothonotary issues the writ
3. Serve the writ (same service rules as a complaint)
4. File the Complaint within a reasonable time (courts monitor)

This two-step approach is frequently used in Pennsylvania when
the SOL deadline is imminent.

## PACFile steps

1. Log in: `https://ujsportal.pacourts.us`
2. Select county and case type
3. Attach complaint and cover sheet as PDFs
4. Pay filing fee electronically
5. Retain the PACFile confirmation and file-stamped documents

## Defendant filing checklist

1. **Answer with New Matter** (within 20 days of service)
   - New Matter = affirmative defenses (Pa. R.C.P. 1030)
   - Counterclaims if applicable (Rule 1031)
2. OR **Preliminary Objections** (within 20 days)
   - Tolls answer deadline
   - Answer due 20 days after preliminary objections are decided
