# Pennsylvania Discovery Framework

Pennsylvania discovery is governed by **Pa. R.C.P. 4001-4025**.

## Discovery tools and limits

| Tool | Rule | Notes |
|---|---|---|
| Interrogatories | 4005 | **25 per side** (including subparts) without leave |
| Requests for Production | 4009 | No numerical limit |
| Requests for Admission | 4014 | No numerical limit |
| Oral Depositions | 4007.1 | No limit without court order |
| Physical/Mental Exam | 4010 | On order; good cause required |

## Key deadlines

- Respond to interrogatories and RFPs: **30 days** after service
- Respond to RFAs: **20 days** (Rule 4014(b)) — failure = admissions

## Motion to Compel

File a **Motion to Compel Discovery** under Pa. R.C.P. 4019.
Include a certification of good-faith effort to resolve.
The court may award sanctions including attorney's fees for
failure to respond (Rule 4019(c)).
