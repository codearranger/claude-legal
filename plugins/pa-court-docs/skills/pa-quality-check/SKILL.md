# Pennsylvania Quality Check

## Format pass
- [ ] Caption: correct court and county
- [ ] Docket number format is correct for this court
- [ ] Signed and dated
- [ ] **Verified** (Pa. R.C.P. 1024) — signed by the party, not the
  attorney, under 18 Pa. C.S. § 4904
- [ ] Filed through PACFile (or paper where permitted)
- [ ] Font ≥ 12 pt, legible, 8.5×11

## Content pass
- [ ] Each cause of action pleads all required elements
  (Pennsylvania fact-pleading standard — not notice pleading)
- [ ] New Matter section includes all affirmative defenses
- [ ] Compulsory counterclaims included if applicable

## Deadline pass
- [ ] SOL verified against 42 Pa. C.S. §§ 5524-5527
- [ ] Answer filed within 20 days of service
- [ ] Good Friday holiday accounted for in deadline computation

## Service pass
- [ ] Certificate of service (Pa. R.C.P. 440) included
- [ ] Service method is permitted under Pa. R.C.P. 440
  (mail to last known address is standard)
