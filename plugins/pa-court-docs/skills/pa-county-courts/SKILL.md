# Pennsylvania County Courts — Roll-Up

Pennsylvania has **67 counties**, each with its own Court of
Common Pleas. This skill covers the populous counties not
served by a dedicated venue skill.

## Court of Common Pleas structure

Each county CCP has multiple divisions:
- **Civil Division** (general civil jurisdiction, no cap)
- **Family Division** (domestic relations, custody, support)
- **Orphans' Court Division** (estates, trusts, guardianship)
- **Criminal Division**
